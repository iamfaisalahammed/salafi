# 🌙 Hikmah — Islamic Learning Platform

**Hikmah** is a modern, responsive Islamic learning platform designed to make Islamic knowledge accessible to everyone.



### 🛠️ Technologies Used
- React.js
- Vite
- JavaScript
- Tailwind CSS
- DaisyUI
- React Router


### 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/iamfaisalahammed/salafi.git
```

Navigate to the project directory:

```bash
cd hikmah
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### 📦 Build for Production

```bash
npm run build
```

### 🎯 Purpose

Hikmah aims to provide a simple and accessible platform for exploring Islamic knowledge, learning about scholars, and discovering valuable educational resources.



*Built with care to make Islamic knowledge easier to explore and access.*
